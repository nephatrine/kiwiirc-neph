# KiwiIRC-Neph

> A static, browser-based IRC client built around modern IRCv3 features.

## Overview

Kiwi IRC is a static web client for one or many IRC networks. It connects
directly over WebSocket or through
[webircgateway](https://github.com/kiwiirc/webircgateway). It focuses on IRCv3,
rich media, themes, and plugins while remaining deployable as plain static
files.

## Features

### Messaging & IRCv3

- Replies, reactions, typing indicators, multiline messages, redactions, read
  markers, and synchronized history.
- Metadata profiles, operator badges, incoming channel rename, Twitch support,
  and bridge/relay support.
- Capability-aware behavior: unsupported IRCv3 features degrade gracefully.

### Themes & Interface

- 38 built-in themes, including Catppuccin, Tokyo Night, Solarized, NephDeck,
  NephWave, and Radioactive.
- Custom theme URLs, light/dark variants, an emoji picker, and modern,
  corporate, compact, inline, or Cyberdeck message layouts.
- Configurable per-network settings and desktop notifications.

### Media & Previews

- Image, audio, and video embeds, with previews for YouTube, Twitch, SoundCloud,
  Spotify, Streamable, Giphy, and RedGifs.
- Imgur image handling, link previews, and per-buffer preview controls.
- Uploads through Litterbox or the server `FILEHOST`.

### Accounts, Bouncers & Notifications

- SASL login, account registration, and per-network persistence preferences.
- Bouncer-managed networks with explicit Save and Connect/Reconnect actions.
- Per-network Web Push, desktop notifications, and synthesized sounds.

### Plugins & Extensibility

- Plugin API for UI hooks, tabs, settings blocks, input commands, autocomplete
  providers, views, sidebars, startup screens, translations, and media playback.
- Bundled channels sidebar, radio, Bongo Companion, NephDeck, NephWave, and
  `suggest-limnoria` plugins.
- See [PLUGINS.md](PLUGINS.md) for plugin authoring and API details.

## Requirements

### Runtime

- Static file hosting on any web server or CDN.
- HTTPS/WSS recommended for production.
- WebSocket proxying when using a gateway; direct connections use the IRC
  server's WebSocket endpoint.
- No server-side application runtime.

### Browsers

- Chrome
- Chrome Mobile (Android)
- Firefox
- Safari 15+
- Edge (Chromium)

A modern browser with WebSocket and localStorage support is required. Web Push
additionally requires HTTPS and service worker support.

### IRC Connectivity

- Direct IRC over WebSocket.
- `webircgateway` for networks without WebSocket support.

### IRC Server Capabilities

No IRCv3 capability is mandatory. Kiwi IRC detects support per connection and
degrades gracefully. For the best experience, servers should support:

- `message-tags`, `echo-message`, `labeled-response`, `server-time`, `batch`
- `draft/chathistory`, `draft/multiline`, `draft/message-redaction`,
  `draft/read-marker`
- SASL, `account-tag`, `account-notify`, `extended-join`, `chghost`, `setname`
- `draft/metadata-2` or `draft/metadata-3`
- `draft/FILEHOST` or `soju.im/FILEHOST` for uploads
- `draft/webpush` or `soju.im/webpush` for push notifications
- `draft/bouncer-networks` or `soju.im/bouncer-networks` for bouncers

See [IRCv3.md](IRCv3.md) for the complete capability matrix.

## Building

**Build Requirement:**

- [Node.js](https://nodejs.org/) 22 or newer.

```bash
git clone https://code.nephatrine.net/nephatrine/kiwiirc.git
cd kiwiirc
npm ci
npm run build
```

This writes the production client to `dist/`. The folder is overwritten each
build; copy its contents to your web server.

Production builds minify application bundles, theme CSS, plugin assets, and
locale JSON. Source maps are generated by default for debugging;
`npm run build:release` omits them for release artifacts.

## Configuration

The browser loads [`static/config.json`](static/config.json) on startup. Use
`?config=<name>` to load `static/config_<name>.json` instead. The file is JSON5,
so comments and trailing commas are allowed.

Configuration is public. Do not put passwords, SASL secrets, or user hashes in
it.

Key settings:

- `startupScreen`: `welcome`, `customServer`, `bouncer`, or `personal`.
- `kiwiServer`: optional WebSocket gateway URL. Leave empty for direct-only
  deployments.
- `restricted`: locks the client to one network.
- `plugins`: enables bundled or custom plugins.

See [CONFIGURATION.md](CONFIGURATION.md) for all options and defaults.

## Recommended IRC Software

Any IRC server works through a gateway, but the servers below provide the best
feature coverage.

### Servers

- [Ergo](https://ergo.chat/) — best match for IRCv3, history, metadata,
  relaymsg, and redaction.
- [Solanum](https://solanum.chat/)
- [InspIRCd](https://www.inspircd.org/)

### Bouncers

- [Soju](https://soju.im/) — best match for `bouncer-networks`, history, and
  `FILEHOST`.
- Other bouncers implementing `draft/bouncer-networks` or
  `soju.im/bouncer-networks`.

## Behavior Notes

- Direct connections use the IRCv3 `text.ircv3.net` WebSocket subprotocol and
  fall back to no subprotocol for legacy servers. Binary WebSocket frames are
  not supported.
- Outgoing messages are most reliable with `echo-message` and
  `labeled-response`. Without them, sends are optimistic and unconfirmed
  messages time out after 60 seconds.
- A bouncer control connection appears as an always-visible `BNC` network. Bound
  networks behave like ordinary IRC connections.
- File uploads require a completed SASL login and a server `FILEHOST` token.
  Plain HTTP is refused when the client connection uses TLS.
- Web Push is a per-network opt-in and requires HTTPS plus server support.
- Twitch connections use Twitch-specific tags and commands and suppress
  unsupported client commands.
- Bridge and relay users are not real IRC users; their profiles may come from
  `RELAYMETA`.
- Kiwi IRC handles incoming `RENAME` but never sends it.
- Bouncer-managed network changes use explicit Save and Connect/Reconnect
  actions.
- Configuration is public, and user settings are stored in browser storage.

## Development & Testing

```bash
npm ci
npm run lint
npm run format
npm test
npm run dev
```

- `npm run dev` serves a hot-reloading client at http://localhost:8080/. Do not
  expose it publicly.
- In development, `static/config.local.json` is copied over
  `dist/static/config.json` if it exists. It is excluded from production builds.

**Generated Assets:**

- `npm run generate:emojis -- /path/to/emoji.json`
- `npm run generate:boxicons`
- `npm run optimize:bongo`

Do not hand-edit generated emoji data, Boxicons CSS, or Bongo WebP files.

## Project Status

Kiwi IRC was created by Darren Whitlen and the KiwiIRC contributors. This fork,
KiwiIRC-Neph, is maintained by Daniel Wolf and is based on the upstream project
at <https://github.com/kiwiirc/kiwiirc>.

This project is here primarily because KiwiIRC plays it safe and does not
aggressively adopt draft or even pre-draft IRC specifications and proposals. I
also wanted a client for my community that supported all the features of our
Discord-IRC bridge and Ergo server to try and bring as much parity as possible
and hopefully entice users over to IRC. A lot of this work was done with AI
assistance. I am an experienced programmer, but webdev is not my wheelhouse ---
I'd prefer to write as little JavaScript as possible and have absolutely no
interest in dealing with Vue 2.

As I am not in a position to really vouch for the AI-generated code being
correct, I would caution against using this in any sort of production context.
Please do report issues, though, and I will attempt to fix them. It works well
with Ergo, Soju, Twitch, and my Discord-IRC fork... but unusual IRC
configuration combinations have not been tested and edge cases may remain.

You can also get help on the `#support` channel at <ircs://irc.nephatrine.net>.
